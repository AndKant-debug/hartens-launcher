# Быстрый лаунчер для Hartens HTY-32H068B-VZ (Android TV 11)

Лёгкий домашний экран без рекламы, рекомендаций и сторонних сервисов. Только системный SDK, никаких библиотек.

- Верхний ряд — избранное. При первом запуске автоматически закрепляются Wink, VK Видео, YouTube/SmartTube и VPN-клиент (по названию).
- Ниже — сетка всех приложений. Долгое нажатие OK на приложении: в избранное / скрыть / о приложении / удалить.
- Кнопка «VPN» открывает установленный клиент (v2rayNG, v2RayTun, Happ, Hiddify), иначе — системные настройки VPN.
- Кнопка «Настройки» — Android, Wi‑Fi, VPN, показать скрытые, сбросить избранное.

## 1. Получить APK (без установки Android Studio)

1. Создайте репозиторий на GitHub, загрузите в него содержимое этой папки (включая `.github`).
2. Вкладка **Actions → Build APK → Run workflow**.
3. Через 2–3 минуты скачайте артефакт `hartens-launcher` — внутри `app-release.apk`.

Либо откройте папку в Android Studio и выберите Build → Build APK(s).

## 2. Подготовить телевизор

1. Настройки → Об устройстве → 7 раз нажать на «Сборка ОС» (включится режим разработчика).
2. Для разработчиков → включить «Отладка по USB» / «Отладка по сети». Запомнить IP телевизора (Настройки → Сеть).
3. На компьютере установить [Android platform-tools](https://developer.android.com/tools/releases/platform-tools) (adb).

## 3. Установить и сделать лаунчер главным

```
install.bat 192.168.1.50 app-release.apk        # Windows
./install.sh 192.168.1.50 app-release.apk       # Linux/macOS
```

На телевизоре подтвердите запрос отладки. Скрипт установит APK, назначит его домашним экраном и уменьшит анимации вдвое. Если после перезагрузки вернулся старый лаунчер — повторите команду `set-home-activity` из скрипта.

Откат: `adb shell cmd package set-home-activity <пакет старого лаунчера>` или удалить приложение.

## 4. Убрать лишнее

Какие именно пакеты стоят на вашей прошивке, я отсюда не вижу, поэтому наугад ничего не отключаю.

```
./debloat.sh 192.168.1.50 list
```

Создастся `packages.txt`. Пришлите его — отмечу, что безопасно отключить. Затем:

```
./debloat.sh 192.168.1.50 disable remove.txt     # отключить (обратимо)
./debloat.sh 192.168.1.50 restore remove.txt     # вернуть
```

Не отключайте: com.android.*, com.google.android.gms, com.google.android.gsf, com.android.vending, системные настройки, Wi‑Fi/Bluetooth и сервис пульта.

## 5. VPN (VLESS + Reality + xhttp)

Рабочий клиент на Android TV: **v2rayNG** (версия с поддержкой xhttp, 1.10+). Apps на sing-box (Hiddify и др.) xhttp могут не поддерживать.

1. Установите v2rayNG на телевизор (`adb install v2rayNG.apk`).
2. Импорт профиля, по удобству:
   - ссылка из `vpn/vless-link.txt`: в v2rayNG «Импорт из буфера обмена» (скопируйте ссылку в буфер любым способом, например через клавиатуру-приложение пульта) или добавьте вручную («Ввести вручную [VLESS]» и заполнить поля из ссылки);
   - либо `vpn/xray-config.json`: `adb push vpn/xray-config.json /sdcard/Download/`, затем в v2rayNG добавить «Свой конфиг из файла». В нём уже настроена маршрутизация: российские сайты (.ru, VK, Wink) идут напрямую, остальное (в том числе YouTube) через VPN.
3. В настройках v2rayNG включите «Проксировать выбранные приложения» (per-app) и выберите только YouTube. Wink и VK Видео лучше оставить без VPN: они российские, работают быстрее и без блокировок по зарубежному IP.
4. Запускайте VPN кнопкой «VPN» в лаунчере.

Параметры подключения: сервер 149.248.79.206:443, VLESS, транспорт xhttp (mode auto, path `/`, host kinopoisk.ru), безопасность reality, SNI kinopoisk.ru, fingerprint firefox, shortId 63.
